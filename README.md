# Умный ежедневник

Учебный проект по дисциплине «Междисциплинарный проектный практикум».
Бэкенд на Django REST Framework, фронтенд на React, аутентификация по JWT.

---

## Что установить один раз

| Программа | Где взять | На что обратить внимание |
|---|---|---|
| **Python 3.12–3.14** | [python.org/downloads](https://www.python.org/downloads/) | При установке обязательно поставить галочку **Add python.exe to PATH** на первом экране |
| **Node.js LTS** | [nodejs.org](https://nodejs.org/) | Ставится с настройками по умолчанию, ничего менять не надо |
| **Git** | [git-scm.com](https://git-scm.com/downloads) | Тоже всё по умолчанию |

После установки закрыть все терминалы, открыть новый и проверить:

```powershell
python --version
node --version
git --version
```

Каждая команда должна напечатать версию. Если пишет «не является внутренней или внешней командой», значит программа не добавилась в PATH — переустановить с нужной галочкой.

## Шаг 1. Скачать проект

```powershell
git clone https://github.com/Seihposwag/mpp.git
```

```powershell
cd mpp
```

---

## Шаг 2. Запустить бэкенд

Создать виртуальное окружение и активировать его:

```powershell
python -m venv venv
```

```powershell
venv\Scripts\activate
```

В начале строки должно появиться `(venv)`. Если PowerShell ругается на запуск скриптов, выполнить один раз и повторить активацию:

```powershell
Set-ExecutionPolicy -Scope Process -Bypass
```

Установить зависимости:

```powershell
pip install -r requirements.txt
```

Создать базу данных и заполнить её тестовыми данными:

```powershell
python manage.py migrate
```

```powershell
python manage.py seed_data
```

Создать свою учётную запись администратора (спросит имя, email и пароль, пароль при вводе не отображается):

```powershell
python manage.py createsuperuser
```

Запустить сервер:

```powershell
python manage.py runserver
```

**Этот терминал не закрывать**, сервер должен работать всё время.

---

## Шаг 3. Запустить фронтенд

Открыть **второй терминал** (в VS Code это плюсик на панели терминала) и перейти в папку фронтенда:

```powershell
cd frontend
```

```powershell
npm install
```

Первая установка занимает пару минут. Потом:

```powershell
npm run dev
```

Этот терминал тоже не закрывать.

## Куда заходить

| Адрес | Что там |
|---|---|
| http://localhost:5173 | Само приложение, формы входа и регистрации, список задач |
| http://127.0.0.1:8000/admin/ | Админ-панель Django, вход под созданным суперпользователем |
| http://127.0.0.1:8000/api/tasks/ | API в браузерном интерфейсе DRF |

Тестовый пользователь из наполнения базы:

```
логин:  testuser
пароль: testpass123
```

У него есть четыре задачи, три проекта и пять тегов. Можно и зарегистрировать нового прямо в приложении, но список задач у него будет пустым — каждый пользователь видит только свои данные.

## Если что-то не работает

**`python` не найден.** Python установлен без галочки Add to PATH. Переустановить, галочка на первом экране установщика.

**`venv\Scripts\activate` не запускается.** Выполнить `Set-ExecutionPolicy -Scope Process -Bypass` и повторить.

**Порт 8000 занят.** Значит сервер уже запущен в другом терминале. Либо закрыть его, либо запустить на другом порту: `python manage.py runserver 8001`. Тогда в файлах `frontend/src/services/authService.js` и `frontend/src/services/api.js` заменить `8000` на `8001`.

**Порт 5173 занят.** Vite сам предложит следующий свободный порт, просто открыть тот адрес, который он напечатает.

**В приложении ошибка 403 или задачи не загружаются.** Проверить, что первый терминал с `runserver` действительно работает и не был закрыт.

**После `git pull` приложение сломалось.** Обновились зависимости, повторить `pip install -r requirements.txt` и `npm install` в папке `frontend`, затем `python manage.py migrate`.

## Структура проекта

```
mpp/
├── smart_diary/      настройки Django и маршруты проекта
├── tasks/            приложение: модели, сериализаторы, представления, API
│   ├── models.py     User, Project, Tag, Task, TaskTag
│   ├── serializers.py
│   ├── views.py
│   └── urls.py       маршруты API и JWT-токенов
├── frontend/         React-приложение
│   └── src/
│       ├── components/   формы входа и регистрации, защита маршрутов, навбар
│       ├── context/      контекст аутентификации
│       └── services/     axios с перехватчиками и сервис аутентификации
├── requirements.txt  зависимости Python
└── manage.py
```
